# v1.6.4 · 方寸有数

- 发布日期：2026-11-04
- 版本号：`1.6.4+24`
- 对比范围：`v1.6.3...v1.6.4`

## 两套页面样式

外观面板新增「页面样式」切换，选择即时生效并持久化，默认「原生」：

| 样式 | 页面 | 卡片 | 头部 |
|---|---|---|---|
| **原生** | 纯色纸底，不铺栏格 | 不透明、预设圆角、0.8px 外框 | 圆角 + 同色辉光 |
| **单行簿** | 18% 透明度、28px 行距的横向账簿栏格 | 透明、方角、1.2px `outline` 外框 | 方角、平贴、无阴影 |

- 两种样式下，四个主页面（总览 / 资产 / 分析 / 设置）的卡片内部都不再设置横向分割线，分行交给留白；单行簿下由背景栏格辅助。
- 详情页、流水页在两种样式下都使用不透明纸卡；单行簿的透明与栏格只作用于四个主页面。

## 设置与外观入口

- 设置页 AppBar 的色盘按钮移除，外观入口迁入「数据管理」卡上方的「外观」卡。
- 外观卡副标题直接显示当前「配色 · 明暗 · 页面样式」，点击打开外观面板。
- 外观面板顺序调整为：页面样式 → 主题配色 → 显示模式。

## 总览头部与品类印记

- 总览头部重做为垂直墨洗，不再使用对角线渐变；下缘用 4px 深墨线收底，底部接纸色账页脚。
- 待更新数量改为方形小印：深墨底、纸色字、2px 内白边。
- 品类图标改为 10px 圆角小方印：品类墨压深做底、2px 纸色压边、反白单字（现 / 债 / 基 / 股 / E / 金 / 自 / 负）。
- 总览头部在原生样式下保留预设圆角与同色辉光；单行簿下保持方角平贴。

## 收益年历与分析

- 收益年历改为 4×3 方角表格，格线由发丝线构成；单元格取消独立描边与圆角，按下不再缩放。
- 「全年 +x.x%」胶囊改为方印，与待更新印形成「印—账」页眉；选中时内白边加粗一档。
- 分析概览在「总投入」前新增「总市值」，沿用只统计理财产品的口径。
- 分析页各卡片取消横向分割线，改用留白与栏格分行。
