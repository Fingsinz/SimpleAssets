## AppBar 溢出菜单

总览、资产、分析三个主页面的 AppBar 右侧只保留一枚「更多操作」，原先并排的图标全部收进同一张纸面菜单：

| 页面 | 菜单项 |
|---|---|
| **总览** | 隐藏金额 / 刷新价格 / 设置 |
| **资产** | 隐藏金额 / 排序：金额降序 / 排序：品类 / 刷新价格 / 显示已清仓资产 / 全部流水 / 设置 |
| **分析** | 隐藏金额 / 刷新价格 / 设置 |

- 菜单沿用下拉与排序共用的纸面弹出样式，40px 行高；当前排序项以主色文字与勾标记。
- 切换类文案直接写当前可执行的动作，例如「隐藏金额」在遮罩开启后变为「显示金额」。
- 刷新进行中，菜单里的「刷新价格」降为 45% 不透明度并禁用。
- 分析页新增「刷新价格」，资产页新增「隐藏金额」，三个主页面的动作集合保持一致。
- 三个菜单都以「设置」收尾；底部「设置」tab 暂时保留，后续替换为其他功能页时摘除。

## 单行簿与空态

- 总览、资产、分析、流水、资产详情与月末价格页的空态统一套用 `AppPage`，新装无数据时切换页面样式也能立刻看到栏格。
- `LedgerSheet` 改用 `StackFit.passthrough`，空态包装后仍保持垂直居中，不会顶到页面顶部。
- 资产页的「显示/隐藏已清仓资产」改为溢出菜单里的文字项，不再使用眼睛图标；眼睛图标只保留给金额遮罩，避免两个开关混淆。

## 性能与交互

- 新增 `ReplayCursor` 增量重放：月度估值只应用新增流水，日期回退时自动重置。
- `BuildPerformance` 与估值器预计算整数日键，区间判断与二分查找不再分配 `DateTime`。
- 资产页与流水页改为 `SliverList` 虚拟化，栏格由 `DecoratedSliver` 绘制，只构建可见条目。
- 新增 `LazyBranch`：未选中的底部 tab 首次进入时才构建，激活后保持挂载与滚动位置。
- 年历、统计曲线与资产页排序共用 `AppDropdown` / `AppPopupMenuTheme` 的纸面菜单样式。
- `beforeOpen` 幂等补 `price_history_holding_observed` 索引。
