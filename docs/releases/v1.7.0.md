## 自由页 · 方寸罐

底部「设置」tab 替换为「自由」页，方寸罐把真实资产折算成一个个基础方寸：

- 净资产 / 总资产可切换，默认净资产；切换后两模块同时重算。
- 每个基础方寸的金额可自定义，默认 ¥100，最小 ¥1，最多两位小数。
- 资产 ÷ 基础方寸价值后按二进制合并：两个 1 合成 2，两个 2 合成 4……最终以 1 / 2 / 4 / 8 / … 的块呈现。
- 块为正方形，面积与方寸数成正比；等级越高块越大、颜色越深。六套主题明暗模式下块面白字对比度均 ≥ 4.5:1。
- 二维货架排布：块从左到右铺排，放不下换行；画布固定 168px 高，零头不画块，只由进度条表达。
- 进度条显示「距下一个方寸」的比例与还差金额；零头为零时显示「已垒满」，资产为零时显示「尚无方寸」。
- 空罐区分「净资产为 0 或为负」「总资产为 0」「资产还不够一个方寸」三种文案。
- 画布提供读屏摘要（方寸总数与最大一块），方块内部不逐个朗读。
- 资产变化时方块做一次 160ms 淡入。

## 自由页 · 自由天数

- 三项月生活成本：最低生存 / 当前生活 / 理想生活，首次进入全部为空，不预填。
- 计算公式：`自由天数 = 资产 ÷ 日成本`，`日成本 = 月成本 × 12 ÷ 365`；天数向下取整，年数保留 1 位小数。
- 卡片标题下直接注明计算公式；点击「编辑」或任一行可打开三项成本的底部弹层。
- 校验：大于 0、最多两位小数；允许清空恢复「未设置」；输入变化时清除错误提示。
- 被动收入：年化取统计页「记录以来年化收益率」，`理论月被动收入 = 资产 × 年化 ÷ 100 ÷ 12`。
- 覆盖率 `= 被动收入 ÷ 当前生活月成本`，只在「当前生活」行显示徽标；大于 9999% 显示「>9999%」。
- 边界降级：年化缺失显示「年化待积累」；非有限数或绝对值 > 1000% 显示「年化异常」；年化 ≤ 0 显示「当前年化为负」；当前成本未设置时只提示设置成本。
- 金额遮罩对月成本、被动收入等金额生效；自由天数、年数、覆盖率不遮罩。

- 底部导航改为「概览 / 资产 / ＋ / 统计 / 自由」，中间 ＋ 仍弹出「添加资产 / 记录交易」。

- 页面标题同步为概览 / 资产 / 统计 / 自由；技术说明页小节改为「收益口径 · 统计」。

## 数值与边界修正

- 方寸零头与理论被动收入的 Decimal 除法显式使用 `scaleOnInfinitePrecision: 20`，修复 `1/3`、`5/6` 等非终止小数在普通输入下抛 `AssertionError` 的问题。
- 年化收益率增加有限性与合理区间（绝对值 ≤ 1000%）检查，避免 `Infinity`、极大值导致崩溃或输出误导性百分比。
- 偏好中的 0 / 负数按默认值或「未设置」处理。
- 空罐进度区不再在资产为零时误显示「已垒满 / 再加 ¥100」。

## 版式修正

- 概览页底部留白 96px → 24px，并让内容至少铺满一屏；一屏放得下时不再产生多余滚动。

- 资产页单行簿样式下用 `SliverFillRemaining` 把栏格铺到整页底部，短列表不再只铺半页。
